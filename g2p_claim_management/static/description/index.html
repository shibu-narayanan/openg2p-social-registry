OpenG2P Claim Management

Streamlined Partial Data Updates

Enable users to raise partial update requests for specific registrant attributes through a configurable, document-driven approval workflow.

🎯 Configurable Claim Types

Define different claim types for various attribute groups like Education Details, Contact Information, Economic Status, and Social Status.

📄 Document Management

Configure mandatory and optional document requirements for each claim type with file format and size validation.

🔄 CR Integration

Seamlessly integrates with existing Change Request workflow - no separate status management required.

✅ Approval Workflow

Reuses existing CR approval infrastructure with enhanced claim-specific information display.

🔒 Security & Access Control

Role-based permissions for claim creation, approval, and management with data isolation.

📊 Audit Trail

Complete tracking of all claim activities and changes with comprehensive logging.
